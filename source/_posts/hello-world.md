# 博客建站记录

这篇文章用来记录博客最初搭建时的几个常用命令，避免保留 Hexo 默认示例文章。

## 常用命令

```bash
hexo new "文章标题"
hexo clean
hexo generate
hexo server
```

## 维护流程

1. 在 `source/_posts` 下写文章，补全标题、日期、分类和标签。
2. 本地运行 `hexo generate` 检查静态页面是否能生成。
3. 内容确认后再提交到 GitHub。

博客的重点不是保留工具说明，而是把项目复盘、学习路径和工程实践整理清楚。
